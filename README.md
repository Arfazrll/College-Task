
# 🎓 College-Task: Informatics Engineering Journey

Welcome to my academic repository! This is a curated collection of materials, codes, and projects studied during my college semesters. It is designed to aid learning and serve as a reference for future studies or anyone interested in these topics.

---

## 📂 Directory Structure

The repository is organized into directories based on the subjects, demonstrating a progression from foundational logic to complex architectural patterns:

### 1. [Programming Introduction](https://www.google.com/search?q=./Programming%2520Introduction) 🐹

Foundational programming concepts including basic logic and control structures using **Go**.

* **Highlights**: Alphanumeric processing, 2D geometry, and basic arithmetic algorithms.

### 2. [Programming Algorithms](https://www.google.com/search?q=./Programming%2520Algorithms) 📈

Implementation of standardized algorithms and optimization problems.

* **Focus**: Sorting (Selection/Insertion), Searching, and Recursive functions in **Go**.

### 3. [Data Structure](https://www.google.com/search?q=./Data%2520Structure) 🏗️

Implementations of core data structures with efficiency analysis.

* **Core Concepts**: Linked Lists, Stacks, Queues, Trees (BST), and Graphs using **C/C++**.

### 4. [Object Oriented Programming](https://www.google.com/search?q=./Object%2520Oriented%2520Programming) ☕

OOP concepts: Inheritance, Polymorphism, and Encapsulation through project-based implementations.

* **Stack**: Java, Maven, and JDBC for database connectivity.

### 5. [Computer Network](https://www.google.com/search?q=./Computer%2520Network) 🔌

Networking protocols, packet analysis, and configurations.

* **Highlights**: TCP/UDP Socket programming, ICMP Client/Server, DHCP Simulation, and Wireshark Analysis.

### 6. [Web Programming](https://www.google.com/search?q=./Web%2520Programming) 🌐

Frontend and Backend development focusing on the evolution from native PHP to modern frameworks.

* **Stack**: HTML, CSS, PHP Native, and **Laravel (MVC)**.
