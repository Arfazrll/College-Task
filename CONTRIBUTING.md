# Contributing Guide

Hi! 👋 Thanks for checking out this repository.

This repository is primarily used for **documenting my college tasks and learning progress**. However, I am open to improvements, corrections, or additional resources that might help me or others learn better.

## How can you contribute?

1.  **Fixing Typos & Bugs**: If you spot an error in the code or documentation, feel free to submit a Pull Request.
2.  **Improving Documentation**: If a README in a subfolder is unclear, clarification is welcome.
3.  **Adding Resources**: If you have a great resource (article, video, pdf) related to one of the subjects, you can add it to the relevant folder.
4.  **Code Optimization**: If you see a way to write a more efficient algorithm (without changing the logic/result of the assignment), let me know!

## How to submit changes

1.  **Fork** the repository.
2.  Create a new **branch** for your feature or fix: `git checkout -b fix/typo-in-readme`.
3.  **Commit** your changes: `git commit -m "Fix typo in README"`.
4.  **Push** to your fork: `git push origin fix/typo-in-readme`.
5.  Open a **Pull Request**.

Thanks!
