Dokumentasi Aplikasi

📋 Fitur Aplikasi:
  • Create: Tambah data mahasiswa melalui form
  • Read: Tampilkan data dalam table dengan DataTables
  • Update: Edit data mahasiswa yang sudah ada
  • Delete: Hapus data mahasiswa dengan konfirmasi
  • Search: Pencarian data dengan jQuery DataTables
  • Sort: Sorting otomatis pada setiap kolom
  • Pagination: Pembagian halaman otomatis
🛠️ Teknologi yang Digunakan:
  • Bootstrap 5: Framework CSS untuk desain responsif
  • jQuery 3.6: Library JavaScript untuk manipulasi DOM
  • DataTables: Plugin jQuery untuk table interaktif
  • JSON: Format penyimpanan data lokal (localStorage)
  • Bootstrap Icons: Icon library
  • HTML5 & CSS3: Struktur dan styling modern
📝 Cara Penggunaan:
  1. Isi form dengan data mahasiswa yang lengkap
  2. Klik tombol "Simpan Data" untuk menambah data baru
  3. Data akan muncul di table di bawah form
  4. Gunakan tombol "Edit" untuk mengubah data
  5. Gunakan tombol "Hapus" untuk menghapus data
  6. Gunakan fitur search di table untuk mencari data
  7. Data tersimpan di localStorage browser
